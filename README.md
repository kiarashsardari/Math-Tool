# Math Tool

`math_tool.py` یک ماژول پایتون برای محاسبات آماری، پردازش آرایه‌ها، تشخیص نوع ماتریس، محاسبه خطا، جمع‌بندی بازه‌ای، مشتق‌گیری نمادین و رسم نمودار مقایسه‌ای است. این ابزار بر پایه `NumPy`، `SymPy` و `Matplotlib` پیاده‌سازی شده و توابع آن برای ورودی‌های لیستی، آرایه‌ای و ماتریسی طراحی شده‌اند.

## معرفی

این فایل یک ماژول مستقل پایتون است که توابع پرکاربرد ریاضی و آماری را در اختیار قرار می‌دهد. تمرکز اصلی ماژول روی موارد زیر است:

- محاسبات آماری پایه مانند میانگین، واریانس و انحراف معیار
- نرمال‌سازی داده‌ها
- محاسبه بازه چبیشف
- تشخیص نوع ماتریس از نظر ساختاری
- محاسبه معیارهای خطا مانند MSE و RMSE
- جمع‌بندی بازه‌ای با تابع دلخواه
- مشتق‌گیری نمادین با `SymPy`
- مقایسه دو تابع با رسم نمودار
- مقایسه برابری ماتریس‌ها

## قابلیت‌ها

- پشتیبانی از ورودی‌های لیستی، چندبعدی و آرایه‌ای
- تبدیل خودکار ورودی‌ها به آرایه یک‌بعدی در توابع آماری
- بازگشت مقدار `None` برای ورودی‌های خالی در توابع آماری

- نرمال‌سازی z-score با مدیریت حالت انحراف معیار صفر
- مشتق‌گیری از عبارات `SymPy` نسبت به یک یا چند نماد
- رسم نمودار مقایسه‌ای برای دو تابع
- جمع‌بندی بازه‌ای با تابع سفارشی

## مرجع توابع

### is_empty

```python
is_empty(x)
```

بررسی می‌کند که آیا ورودی از نظر تعداد عناصر خالی است یا نه.

- **ورودی:** `x` — هر مقدار قابل تبدیل به آرایه
- **خروجی:** `bool`
- **منطق:** اگر `np.asarray(x).size == 0` باشد، مقدار `True` برمی‌گرداند.

```python
mt.is_empty([])        # True
mt.is_empty([1, 2])    # False
```

### flat_and_array

```python
flat_and_array(x)
```

ورودی را به آرایه `NumPy` تبدیل کرده و آن را به شکل یک‌بعدی درمی‌آورد.

- **ورودی:** `x` — لیست، آرایه یا مقدار عددی
- **خروجی:** `numpy.ndarray` یک‌بعدی

```python
mt.flat_and_array([[1, 2], [3, 4]])
# array([1, 2, 3, 4])
```

### loc

```python
loc(nums)
```

میانگین عناصر ورودی را محاسبه می‌کند.

- **ورودی:** `nums` — لیست یا آرایه اعداد
- **خروجی:** میانگین به‌صورت عدد یا `None` برای ورودی خالی

```python
mt.loc([1, 2, 3, 4])   # 2.5
mt.loc([])             # None
```

### variance

```python
variance(nums)
```

واریانس جامعه‌ای عناصر را محاسبه می‌کند. در این پیاده‌سازی مجموع مربعات اختلاف از میانگین بر تعداد عناصر تقسیم می‌شود.

- **ورودی:** `nums` — لیست یا آرایه اعداد
- **خروجی:** واریانس یا `None` برای ورودی خالی

```python
mt.variance([1, 2, 3, 4])   # 1.25
mt.variance([])             # None
```

### scale

```python
scale(nums)
```

انحراف معیار جامعه‌ای را محاسبه می‌کند؛ یعنی جذر واریانس.

- **ورودی:** `nums` — لیست یا آرایه اعداد
- **خروجی:** انحراف معیار یا `None` برای ورودی خالی

```python
mt.scale([1, 2, 3, 4])
# 1.118033988749895
```

### chebyshev

```python
chebyshev(nums, k)
```

بازه چبیشف را بر اساس میانگین و انحراف معیار محاسبه می‌کند.

- **ورودی‌ها:**
  - `nums` — لیست یا آرایه اعداد
  - `k` — ضریب مثبت
- **خروجی:** تاپل `(mean - k * std, mean + k * std)` به‌صورت اعداد اعشاری
- **استثنا:** اگر `k <= 0` باشد، `ValueError` ایجاد می‌شود.
- **رفتار برای ورودی خالی:** `None`

```python
mt.chebyshev([1, 2, 3, 4], 2)
# (0.2639320225002102, 4.73606797749979)
```

### norm

```python
norm(x_s)
```

نرمال‌سازی z-score را انجام می‌دهد:

\[
z = \frac{x - \mu}{\sigma}
\]

- **ورودی:** `x_s` — لیست یا آرایه اعداد
- **خروجی:** آرایه نرمال‌شده یا `None` برای ورودی خالی
- **نکته:** اگر انحراف معیار صفر باشد، آرایه یک‌بعدی ورودی بدون تغییر برگردانده می‌شود.

```python
mt.norm([1, 2, 3])
# array([-1.22474487,  0.        ,  1.22474487])
```

### detect_matrix

```python
detect_matrix(M)
```

نوع ماتریس را تشخیص می‌دهد و شکل آن را برمی‌گرداند.

- **ورودی:** `M` — ماتریس یا آرایه
- **خروجی:** تاپل `(typ, shape)`
- **رفتارها:**
  - برای ورودی خالی: `(None, M.shape)`
  - برای آرایه صفر‌بعدی یا یک‌بعدی: ابتدا به شکل `(1, -1)` تبدیل می‌شود.
  - برای آرایه با ابعاد بیشتر از دو: `ValueError`
  - اگر همه عناصر صفر باشند: نوع `null`
  - ماتریس مربعی غیرقطری: `square`
  - ماتریس مربعی قطری با عناصر قطری نابرابر: `diagonal`
  - ماتریس مربعی قطری با عناصر قطری برابر: `scalar`
  - ماتریس اسکالر با مقدار قطری `1`: `identity`
  - ماتریس یک‌ستونی با بیش از یک سطر: `column`
  - ماتریس یک‌سطری با بیش از یک ستون: `row`
  - سایر حالت‌ها: `rectangular`

```python
mt.detect_matrix([[1, 0], [0, 1]])
# ('identity', (2, 2))

mt.detect_matrix([[2, 0], [0, 2]])
# ('scalar', (2, 2))

mt.detect_matrix([[1, 2], [3, 4]])
# ('square', (2, 2))

mt.detect_matrix([[0, 0], [0, 0]])
# ('null', (2, 2))
```

### mse

```python
mse(y_true_array, y_pred_array)
```

میانگین مربعات خطا را محاسبه می‌کند.

- **ورودی‌ها:**
  - `y_true_array` — مقادیر واقعی
  - `y_pred_array` — مقادیر پیش‌بینی‌شده
- **خروجی:** مقدار MSE یا `None`
- **شرط:** دو ورودی باید پس از تبدیل به آرایه، تعداد عناصر یکسان و غیرصفر داشته باشند؛ در غیر این صورت `None` برگردانده می‌شود.

```python
mt.mse([1, 2, 3], [1, 2, 4])
# 0.3333333333333333
```

### rmse

```python
rmse(mse_value)
```

جذر مقدار MSE را محاسبه می‌کند.

- **ورودی:** `mse_value` — مقدار MSE
- **خروجی:** مقدار RMSE یا `None` در صورت `None` بودن ورودی

```python
mt.rmse(0.3333333333333333)
```

```python
comparison_plot(f_true, f_pred)
```

دو تابع را روی بازه `[1, 10]` با ۱۰۰ نقطه رسم و مقایسه می‌کند.

### sigma

```python
sigma(i, n, f=lambda x: x)
```

جمع‌بندی بازه‌ای را از `i` تا `n` به‌صورت شامل انجام می‌دهد:

\[
\sum_{j=i}^{n} f(j)
\]

- **ورودی‌ها:**
  - `i` — ابتدای بازه
  - `n` — انتهای بازه
  - `f` — تابعی که روی هر مقدار اعمال می‌شود
- **خروجی:** حاصل جمع
- **استثنا:** اگر `i` یا `n` عدد صحیح نباشند یا از نوع `bool` باشند، `TypeError` ایجاد می‌شود.
- **نکته:** اگر `i > n` باشد، حاصل جمع برابر `0` است.

```python
mt.sigma(0, 10, lambda x: 2*x**2 + 3*x - 3)
# 902
```

### matrix_equal

```python
matrix_equal(A, B)
```

برابری دو ماتریس را بررسی می‌کند.

- **ورودی‌ها:** `A` و `B`
- **خروجی:** `bool`
- **منطق:** ابتدا شکل دو آرایه مقایسه می‌شود؛ در صورت برابر بودن شکل، `np.array_equal` استفاده می‌شود.

```python
mt.matrix_equal([[1, 2]], [[1, 2]])   # True
mt.matrix_equal([[1, 2]], [[1, 3]])   # False
```

### derivative

```python
derivative(f, *symbols)
```

مشتق عبارت `SymPy` را نسبت به یک یا چند نماد محاسبه می‌کند.

- **ورودی‌ها:**
  - `f` — عبارت `SymPy`
  - `*symbols` — نمادها؛ می‌توانند `SymPy Symbol` یا رشته باشند
- **خروجی:** لیستی از مشتق‌ها به ترتیب نمادهای ورودی

```python
import sympy as sp

x = sp.Symbol('x')
f = 2*x**2 + 3*x - 3

mt.derivative(f, 'x', 'y')
# [4*x + 3, 0]
```

## مثال‌های کاربردی

### محاسبات آماری روی ماتریس

```python
import math_tool as mt

A = [
    [6, 0, 0],
    [0, 2, 0],
    [0, 0, 3]
]

print("mean:", mt.loc(A))
print("variance:", mt.variance(A))
print("std:", mt.scale(A))
print("chebyshev:", mt.chebyshev(A, 3))
print("normalized:", mt.norm(A))
```

### تشخیص نوع ماتریس

```python
matrices = {
    "identity": [[1, 0], [0, 1]],
    "scalar": [[5, 0], [0, 5]],
    "diagonal": [[1, 0], [0, 2]],
    "square": [[1, 2], [3, 4]],
    "column": [[1], [2]],
    "row": [[1, 2]],
    "null": [[0, 0], [0, 0]]
}

for name, M in matrices.items():
    print(name, "->", mt.detect_matrix(M))
```

### محاسبه خطا

```python
y_true = [3, -0.5, 2, 7]
y_pred = [2.5, 0.0, 2, 8]

mse_value = mt.mse(y_true, y_pred)
print("MSE:", mse_value)
print("RMSE:", mt.rmse(mse_value))
```

### جمع‌بندی و مشتق

```python
import sympy as sp
import math_tool as mt

total = mt.sigma(1, 5, lambda x: x**2)
print("sum:", total)

x = sp.Symbol('x')
expr = x**3 + 2*x**2 + x
print("derivative:", mt.derivative(expr, 'x'))
```

### رسم نمودار مقایسه‌ای

```python
import math_tool as mt

mt.comparison_plot(
    f_true=lambda x: 2*x**2 + 3*x - 3,
    f_pred=lambda x: 2*x**2 + 2*x - 3
)
```

## نکات پیاده‌سازی

- توابع آماری ورودی را با `flat_and_array` به آرایه یک‌بعدی تبدیل می‌کنند؛ بنابراین ماتریس‌ها نیز به‌صورت مجموعه‌ای از عناصر مسطح پردازش می‌شوند.
- `variance` و `scale` از فرمول جامعه‌ای استفاده می‌کنند و تقسیم بر تعداد عناصر انجام می‌شود، نه `n - 1`.
- در `norm` اگر انحراف معیار صفر باشد، خروجی همان آرایه مسطح‌شده ورودی است.
- در `detect_matrix` ابتدا حالت صفر بودن کل ماتریس بررسی می‌شود؛ بنابراین ماتریس صفر از نوع `null` گزارش می‌شود.
- `detect_matrix` برای آرایه‌های یک‌بعدی آن‌ها را به شکل یک سطر در نظر می‌گیرد.
- `mse` فقط زمانی مقدار عددی برمی‌گرداند که اندازه دو ورودی برابر و غیرصفر باشد.
- `sigma` بازه را به‌صورت شامل از `i` تا `n` پیمایش می‌کند.
- `derivative` خروجی را به‌صورت لیست برمی‌گرداند؛ حتی اگر فقط یک نماد وارد شده باشد.
- `comparison_plot` بازه رسم را به‌صورت ثابت از `1` تا `10` با ۱۰۰ نقطه در نظر می‌گیرد.
- برای استفاده از `derivative` باید عبارت ورودی از نوع عبارات `SymPy` باشد.
